# تكامل CCAvenue السعودية — متجر إيقاع الحياة

يُفضَّل استخدام تدفق صفحة دفع مستضافة أو رابط دفع من CCAvenue، بحيث ينشئ المتجر طلب السداد ويحوّل العميل إلى صفحة المشغّل لإدخال معلومات البطاقة. لا تُخزّن منصة المتجر أرقام البطاقات أو رموز التحقق.

| قدرة المشغّل | الاستخدام في المتجر |
|---|---|
| Payment Links | إنشاء رابط سداد وإرساله للعميل عبر واتساب أو البريد. |
| Invoice Payments | إنشاء فاتورة بعناصرها ثم متابعة سدادها. |
| Hosted Checkout / iFrame | إتمام الدفع عبر واجهة CCAvenue مع الحفاظ على خصوصية بيانات البطاقة. |
| Dynamic Event Notification | تحديث حالة الفاتورة أو الطلب بعد استلام إشعار من المشغّل. |

قبل البدء بالتكامل الحي، يلزم أن يوفّر مالك الحساب بيانات التكامل الممنوحة من CCAvenue وبيئة اختبار إن كانت متاحة. تحفظ القيم في إعدادات الخادم السرية فقط، ولا توضع في واجهة المتجر أو في المستودع. بعد التفعيل، يجب ضبط روابط العودة والإشعارات لتشير إلى نطاق المتجر `https://ayqaealhayaa.sa`.

## ما ظهر في حساب التاجر

تتوفر داخل حساب CCAvenue أقسام **API Keys** و**Integration Kit** و**Dynamic Event Notification**، إضافة إلى أقسام الفواتير والطلبات. لذلك سيكون المسار الآمن هو أخذ قيم الربط من قسم API Keys، والاعتماد على Integration Kit لتطبيق التشفير والتوقيع وفق إصدار الحساب، ثم تسجيل رابط الإشعارات في Dynamic Event Notification. لا تُنسخ أي قيمة حساسة إلى المحادثة.

تم تدوير مفتاح التشفير المعروض سابقًا بتفويض من مالك الحساب. حُفظت بيانات الربط عبر إعدادات الخادم السرية، واجتاز فحص الحالة الخادمي بنجاح؛ لا يحتوي هذا الملف أو سجل المشروع على قيم المفاتيح.

صفحة الدفع الإنتاجية التي تم التحقق من استجابتها هي `https://secure.ccavenue.sa/transaction/transaction.do?command=initiateTransaction`. يظهر في حساب التاجر أن مفاتيح الربط الحالية مرتبطة بنطاق `https://ayqaealhayaa.sa`.

يعرض دليل الحساب أقسامًا مخصصة لبيئة الاختبار والإنتاج، وطرق الربط، وصفحة دفع CCAvenue المستضافة، ومعلمات الرد، وأفضل ممارسات سلامة المعاملات. سيستخدم المتجر صفحة CCAvenue المستضافة بدل إدخال أي بيانات بطاقة في نطاق المتجر.

تعرض صفحة **Dynamic Event Notification** في حساب التاجر حقلاً منفصلاً لإشعار **Order Status** الذي يرسل طلب HTTP POST عند اكتمال الدفع. لا يُفعّل هذا الحقل إلا بعد نشر معالج الإشعار والتحقق منه؛ يعالج المتجر نتيجة الدفع المشفّرة في رابط العودة أولًا، ثم يمكن إضافة رابط إشعار حالة الطلب كطبقة متابعة إضافية بحسب صيغة الحدث الموضحة في حساب التاجر.

رابط الإشعار المنشور المخصص لحقل **Order Status** هو:

`https://ayqaealhayaa.sa/api/payment-links/v1/ccavenue/events/order-status`

يسجل الرابط مرجع الطلب وحالة الطلب ورقم التتبع للمراجعة، ولا يقبل اعتبار الإشعار غير الموثق إثباتًا للسداد. إثبات السداد لا يتم إلا عبر نتيجة CCAvenue المشفرة المطابقة لمرجع الفاتورة ومبلغها وعملتها.
