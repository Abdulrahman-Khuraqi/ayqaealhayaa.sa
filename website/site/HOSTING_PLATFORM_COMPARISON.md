# مقارنة منصات إدارة واستضافة متجر إيقاع الحياة

## ملخص المصادر الرسمية

توضح وثائق سلة توفر لوحة موسعة لإدارة المنتجات والمخزون والمستودعات والطلبات وحالاتها واسترجاعها، وإعدادات الدفع والفوترة والشحن، إضافة إلى النطاقات والموظفين والتطبيقات وواجهات الويب هوك. وتوضح وثائق إضافة الطلب اليدوي أن التاجر يستطيع إنشاء طلب للطلبات الهاتفية أو المباشرة وإرساله برابط دفع.

توضح صفحة زد الرسمية أنها منصة متكاملة للتجارة الإلكترونية، وتشمل المتجر والدفع والشحن وإدارة المخزون والتسويق، كما تعرض نقطة بيع وربط قنوات البيع وتطبيقات إضافية.

توضح Shopify أن بوابات الدفع المستضافة تعيد العميل إلى صفحة البوابة لمعالجة البطاقة، وأن المنصة تدعم اختيار مزودي دفع بحسب الدولة، ومن ضمن الدول المعروضة السعودية.
