# إيقاع الحياة — V3

موقع ثابت (Static) مبني بـ Next.js ويُصدَّر كملفات HTML جاهزة للرفع على أي استضافة.

- **الهوية البصرية** من V1: فحم دافئ `#15110f`، برونزي `#C88A5A`، رمل فاتح، وخطا Changa وIBM Plex Sans Arabic، مع شعار V1.
- **المحتوى والمنتجات** من V2: كتالوج 223 منتجًا و13 قسمًا رئيسيًا (`data/catalog.ts` و`data/main-categories.ts`).
- **إضافات V3**: خدمات البرمجة، الاستضافة والنطاقات، المنتجات الرقمية، وسبع صفحات سياسات مناسبة للأنظمة السعودية.

## التشغيل

```bash
npm install
npm run dev      # تطوير على http://localhost:3000
npm run build    # يولد الموقع الثابت في مجلد out/
```

ارفع محتوى `out/` كما هو إلى الاستضافة (Netlify، Cloudflare Pages، Vercel، أو أي خادم ملفات).

## كيف يعمل الطلب

الموقع ثابت بلا خادم، لذلك تُحفظ السلة في متصفح العميل. عند إتمام الطلب تُجهَّز رسالة واتساب برقم طلب وتفاصيل المنتجات والإجمالي والضريبة وبيانات العميل، ثم يُرسَل للعميل رابط الدفع يدويًا. يمكن لاحقًا ربط بوابة دفع مباشرة دون تغيير التصميم.

## قبل الإطلاق

- راجع أسعار الخدمات والاستضافة والمنتجات الرقمية في ملفات `data/`؛ هي أسعار مقترحة.
- صور المنتجات مرتبطة بروابط خارجية من مصدر كتالوج V2؛ يُفضّل نقلها إلى استضافتك أو استبدالها بصورك.
- راجع نصوص السياسات مع مستشار نظامي قبل النشر.

## النشر التلقائي (FTP)

كل دفع إلى فرع `site-dev` يشغّل `.github/workflows/deploy.yml`: يبني الموقع ويرفع مجلد `out/` عبر FTP.
الأسرار المطلوبة في Settings → Secrets and variables → Actions: `FTP_SERVER`، `FTP_USERNAME`، `FTP_PASSWORD`.
اختياري: متغير `FTP_SERVER_DIR` لمجلد الموقع على الخادم (مثل `public_html/`)، والافتراضي جذر حساب FTP.
